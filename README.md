# Public Goods Application Toolkit

An open toolkit for writing grant applications a reviewer can actually verify — built from a full
retrospective of every proposal one public grant programme received over two years.

## 为什么有这个东西

Conflux Integration Grants 两年收到 **36 份提案，只批了 4 份**（约 11%）；15 份挂着没有任何结论，
最老的一份从 2024-08 挂到 2026-09。更关键的是，被拒的绝大多数只收到一句
`did not pass the grant committee's decision` —— **标准从来没被写下来，所以没人能从中学会**。

这个仓库把那套标准写下来。

## 里面有什么

| 文件 | 是什么 |
| --- | --- |
| `checklist.html` | 40 项校验清单，单文件、零外链、可直接在浏览器打开或打印 |
| `checklist.pdf` | 同一份清单的 PDF 版本（2 页 A4，适合当附件） |
| `checklist.md` | 清单的纯文本源文件（便于 diff 和 fork） |
| `grant-application-template.md` | 过审模板「6 块」：问题→生态因果链 / 里程碑 / 预算 / 专属 KPI / 可验证交付物 / 团队合规 |
| `.github/ISSUE_TEMPLATE/application.md` | 把「我要申请」变成一张结构化任务单，逐条勾完再动笔 |

## 怎么用

1. 打开 `checklist.html`，从第 1 条往下勾。每条都有「判定方式」——不是「写得好不好」，而是「怎么算通过」。
2. 勾不过的项，对着 `grant-application-template.md` 对应那一块补。
3. 全过之后再提交。清单末尾有「提交前 6 步」。
